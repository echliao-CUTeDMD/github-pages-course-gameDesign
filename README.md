# 114下_遊戲程式設計｜深坑夜市大集合

這是課程成果展示網頁的 GitHub Pages 版本。

## 上傳方式

1. 將本資料夾內的所有檔案上傳到 GitHub repository 根目錄：
   - `index.html`
   - `course_showcase_assets/`
   - `.nojekyll`
2. 到 GitHub repository 的 `Settings` -> `Pages`。
3. Source 選擇 `Deploy from a branch`。
4. Branch 選擇 `main`，資料夾選擇 `/root`。
5. 儲存後等待 GitHub Pages 產生網址。
